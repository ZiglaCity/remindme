## Checks still needed before closing earlier phases

1. **Google OAuth:** use a consent-screen test account and the documented callback. Confirm first login, reload persistence, logout/relogin and owned preferences. With a controlled email/password account sharing the provider email, verify it signs into the same user ID with existing reminders/preferences and that password sign-in still works. Unverified Google profiles must not link. Do not use a real account with valuable data for collision testing. See [authentication setup](./authentication.md).
2. **Voice permissions:** in Chrome, retain some typed text, deny access and try voice. Confirm an actionable error, preserved text and working manual creation. Reallow access and confirm a new capture works. Firefox should offer typing rather than falsely implying that permission grants speech recognition support.
3. **Accessibility:** complete a real keyboard-only pass through auth, capture, clarification/review, manual creation, editing and delete/cancel; check focus visibility/order and errors. Use a screen reader to verify labels, state/error announcements and recovery. Existing labels/focus code are implementation evidence, not a completed assistive-technology audit.
4. **Worker failure drills:** use an isolated database, synthetic records and a local fake SMTP destination. Exercise a lost database connection and later successful invocation, stalled SMTP beyond its deadline, termination before send and termination after fake acceptance but before persistence. Inspect uncertain history, fencing, backoff and recovery caps. Do not send real mail or reset uncertain production records. Existing mocked/lease-state tests remain separate evidence.
5. **Physical PWA:** on Android and iOS, install, open from the home screen, confirm `/app`/sign-in routing, test generic offline navigation and install an update without losing a draft. A device needs a suitable trusted origin; final production HTTPS checks necessarily follow Phase 8 hosting. See [installation instructions](./ui-pwa.md).
